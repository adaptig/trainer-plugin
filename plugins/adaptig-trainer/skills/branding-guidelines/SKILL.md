# Branding guidelines for trainers

Make the requested material visually consistent with Adaptig. This is the base plugin's
visual guide; `brand-voice` handles the writing. Both are included in one installation.
Read [the visual reference](references/visual-basics.md) and use the real assets listed
in [the asset guide](assets/README.md). No other brand plugin or internal repository is
required for these assets.

## Apply the guide to the requested output

1. Identify the audience, format, language and actual trainer identity. Use the current
   approved template if supplied; otherwise use this bundled visual snapshot. Identify
   a newer supplied brand revision rather than mixing versions silently.
2. Select genuine logo/shape files from `assets/`. Preserve aspect ratio and logo
   clearspace. Use the palette, permitted type and co-branding rules in the reference.
   A generic icon is not a company mark or evidence of certification.
3. For a proposal, one-pager, client presentation or workshop pack, follow that output
   skill's actual renderer. These skills include usable document templates; this guide
   does not turn a description into a produced artifact.
4. Use icons only when they explain a label or action. The supplied Lucide utility
   icons are separately licensed general-purpose icons, not a newly approved Adaptig
   symbol system. Keep their source attribution/licence with distributed source.
5. Inspect the actual result at its intended size: logo placement, hierarchy, contrast,
   source-note readability, icon labels, wrapping and image crop. Check print when
   exporting a print document. Correct the rendered file before handover when possible.

Use the author's actual voice and the `brand-voice` helper for copy. Refer to current
supplied offer information for product facts. Do not invent company results, client
logos, trainer credentials or claims to complete a design. A branding request does not
authorize a new identity, certificate, public post or external file write.

## Deliver and fall back honestly

Apply branding directly to the requested artifact and retain its editable source.
State its actual format and inspection status. If the host cannot render, supply the
supported editable source and the precise missing capability; do not claim a finished
PDF, slide deck or graphic exists. If an asset variant is missing, use a supplied
supported variant or the company name in text; do not redraw a logo.

Proxima
Nova is not included or licensed to trainers by this pack. The bundled open fonts and
their OFL notices support portable outputs; a separately supplied commercial font
needs its actual licence. Brand artwork retains Adaptig's rights.

## Language

Answer the trainer in the language they write to you in. Write anything a client will read in the language the trainer names; when they name none, use the language of their brief or notes.


## Self-Improvement Loop

Suggest one focused change only when an actual output reveals a reusable defect. Use
a synthetic example and identify the source brand revision. Never silently change
installed brand rules, recolour artwork, publish a new brand or submit feedback.
