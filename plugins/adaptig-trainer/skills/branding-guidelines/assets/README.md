# Bundled assets

Use these local source files; no brand-service login is needed. `asset-manifest.json`
records each file's source and SHA-256 for update review.

| Folder | Included material |
|---|---|
| `logos/` | Genuine Adaptig wordmark and logomark PNGs |
| `shapes/` | Six original shape/colour variants from the trainer-safe brand bundle |
| `fonts/` | Bricolage Grotesque and Figtree WOFF2 subsets with both OFL notices |
| `icons/` | Calendar, check, clipboard, document, lightbulb, feedback, presentation and group SVGs with the Lucide ISC licence |

The existing output skills retain their own minimal renderer assets so their individual
archives remain usable. Duplicated font/logo files are intentional portable snapshots;
review source hashes when updating the brand rather than editing a rendered copy.

Adaptig artwork remains Adaptig brand material; this pack is not a right to register or
resell its marks. Fonts and Lucide icons have their own included open-source licences.
The icons were retrieved from official Lucide revision
`c1a02a04d4f3f7049d44567d62b8b06cff0b9103` on 20 November 2026.
No proprietary Proxima Nova file, client logo or stock image is included.
